# Ikony rozszerzenia

Ten folder powinien zawierać następujące pliki PNG:
- `icon16.png` (16x16 pikseli)
- `icon48.png` (48x48 pikseli)
- `icon128.png` (128x128 pikseli)

## Jak stworzyć ikony

Możesz użyć jednej z następujących metod:

### Metoda 1: Użyj create-icons.html
1. Otwórz plik `create-icons.html` w przeglądarce
2. Ikony zostaną automatycznie pobrane

### Metoda 2: Użyj narzędzia online
- [Favicon Generator](https://favicon.io/favicon-generator/)
- [RealFaviconGenerator](https://realfavicongenerator.net/)

### Metoda 3: Stwórz własne
Użyj dowolnego edytora grafiki (GIMP, Photoshop, Figma) aby stworzyć ikony z symbolem odtwarzacza wideo lub strzałki w dół.

## Tymczasowe rozwiązanie

Jeśli nie masz ikon, możesz użyć prostych placeholder ikon. Rozszerzenie będzie działać, ale ikona będzie domyślna ikona Chrome.
