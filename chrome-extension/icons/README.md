# Icons

This folder should contain the following PNG files:

- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

## How to create icons

Pick one of the methods below:

### Method 1: use create-icons.html

1. Open `create-icons.html` in a browser.
2. The icons are generated/downloaded automatically.

### Method 2: use an online tool

Use an icon generator (e.g. an online icon editor) to create the three sizes.

### Method 3: make your own

Use any graphics editor (GIMP, Photoshop, Figma) to create icons with a
video player or down-arrow symbol.

## Temporary fallback

Without icons the extension still works, but Chrome shows its default
extension icon.
